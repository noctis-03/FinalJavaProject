## 버그 및 기능 요청 정리

### 노드(포트) 관련

- 입력 포트 등 원(노드)의 크기를 줄이기
- 노드는 항상 보이지 않고, 실행 블록의 노드를 드래그할 때만 표시되도록 변경
- 출력 노드는 항상 표시되도록 수정
- 블록 왼쪽에만 있는 노드 외에 오른쪽에도 노드 추가
- 오른쪽 노드를 통해 다른 블록의 왼쪽 노드로 연결 가능하도록 구현
- 노드를 마우스로 끌어서 연결을 뗄 수 있도록 구현

### 실행 블록 관련

- 실행 블록과 연결된 블록을 삭제할 때, 리스트에서 해당 연결이 사라지지 않는 버그 수정

### 블록 크기 관련

- 블록 크기를 너무 줄였을 때 텍스트가 블록 밖으로 삐져나오는 문제 수정
- 블록 크기 조절(리사이즈) 시에도 스냅 기능 적용
- 블록 크기 조절 범위가 내용(텍스트 등) 영역 밖으로 나가도 정상 동작하도록 수정

### 과목 탭 관련

- 파일 칸에 파일 추가 시, 파일 이름 길이에 따라 칸 크기가 늘어나는 문제 수정

### 캘린더 관련

- 미리블록을 캘린더에 추가한 후, 앱을 껐다 켜면 저장되지 않는 버그 수정
-  과목 추가 시 1학기 / 2학기 선택 가능하도록 추가 (1학기: 3월~6월 말, 2학기: 9월~12월)
-  과목 추가 시 캘린더 뷰에 자동 동기화되도록 구현
-  캘린더 뷰의 일정 블록을 드래그 앤 드롭으로 이동, 클릭으로 시간 상세 설정 가능하도록 구현
-  과목 추가로 생성된 일정 블록도 일반 일정 블록과 동일하게 드래그 앤 드롭 이동 및 클릭 상세 설정 가능하도록 구현
- 일정 블록 삭제 기능 추가
- "시간표 입력" 버튼 클릭 시 나오는 창에서 과목 수정 및 삭제 기능 추가
- 일정 추가 시 기존 일정과 시간이 겹치는 경우 생성되지 않도록 검증 추가
