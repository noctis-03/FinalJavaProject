# 2. 프로젝트 배경

---

## 2.1 분산된 학업 관리 도구

대학생은 다음 항목을 **각기 다른 서비스**에서 따로 관리한다.

- 시간표 · 일정 → 캘린더 앱
- 과제 · 공지 → LMS
- 강의 자료 · 제출물 → 클라우드 저장소 / 이메일

➡ 정보가 여러 플랫폼에 흩어져 있어, 필요한 정보를 찾기 위해 매번 여러 앱을 오가야 한다.

---

## 2.2 학업 자료 관리의 어려움

**학기가 진행될수록 증가하는 자료**

- 강의 슬라이드
- 참고 자료
- 과제 제출물

**자료들은 LMS / 이메일 / 클라우드 저장소에 분산 저장됨**

➡ 특히 LMS의 강의 콘텐츠 구조는 자료 탐색이 불편하여, 원하는 파일을 찾는 데 많은 시간이 소요된다.

---

## 2.3 자주 바뀌는 일정

대학생의 일정은 다음과 같은 이유로 자주 변경된다.

- 교수님의 일정 변경
- 공휴일 보강
- 팀 프로젝트 회의 조율 

➡ 이러한 유동적인 일정은 **학기 중 일정 관리의 피로도**를 높인다.

---

## 2.4 사용자화의 한계

**기존 LMS 제공 기능**: 과제 공지 · 자료 배포 · 성적 확인

**하지만…**

- 대시보드에 과제·공지·강의 자료가 혼합되어 있고 **필터링 기능 없음**
- 업로드된 파일의 위치를 임의로 수정 불가
- 즉, 사용자가 자신에게 맞게 **구조를 재구성('사용자화')하는 것이 불가능**

# 3. 프로젝트 목적

---

## 3.1 해결하고자 하는 문제

현재 대학생들은 다음 항목을 **각각 다른 서비스**에서 관리하고 있다.

- 시간표 (캘린더 앱, 학교 포털)
- 과제 (LMS)
- 강의 자료 (클라우드 저장소, 이메일)
- 개인 일정 (개인용 캘린더 앱)

<br>

> 본 프로젝트는 이러한 분산된 학업 관리 흐름을
> **하나의 블록 편집 기반 인터페이스로 통합**하여
> 사용자화하는 것을 목표로 한다.

---

## 3.2 블록 편집 기반 인터페이스

**블록 기반 인터페이스란?**

- 모든 정보를 블록 단위로 구조화
- 시각적으로 정보를 파악
- 드래그 앤 드롭으로 빠른 조작 가능

### 기대 효과

- 정보 구조를 한눈에 파악
- 일정 변경 시 유연한 수정
- 직관적인 사용자 경험 제공

---

## 3.3 대상 사용자

본 프로젝트는 **대학생 전용 프로그램**이다.

**주요 사용자**

- 여러 과목의 과제와 시험 일정을 관리해야 하는 학생
- 운동, 동아리, 아르바이트 등 유동적으로 변하는 일정을 함께 관리하고자 하는 학생
- 강의 자료와 제출 파일을 체계적으로 정리하고 싶은 학생
- Google Calendar 등 범용 도구에 아쉬움을 느끼는 학생
